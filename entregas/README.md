# Carpeta de Entregas (TP3 - Modelos y Simulación)

Coloca aquí el archivo `.json` que descargaste desde la plataforma web `index.html` tras alcanzar **100/100 Pts** en tu ejercicio asignado.

El nombre del archivo descargado tiene el formato:
`comprobante_tp3_ejercicio_XX_tuLegajo.json`

Una vez colocado el archivo aquí:
1. Puedes autoevaluarte localmente ejecutando `./test.sh` (o `test.bat` en Windows).
2. Haz `git add entregas/`, `git commit -m "Entrega TP3"` y `git push`.
3. GitHub Actions ejecutará el autograder y marcará tu entrega con tilde verde ✅ en GitHub Classroom.
